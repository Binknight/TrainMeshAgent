# TrainMesh Agent 用户操作指南

## 页面布局

打开浏览器访问系统地址后，你会看到三栏式界面：

```
┌──────────┬───────────────────────────┬──────────┐
│  📋      │                           │  💬      │
│  历史任务 │       主画布区域           │  Agent   │
│  侧边栏   │   等效建模 / 仿真 / 结果   │  对话栏   │
│          │                           │          │
│ [+新任务] │                           │  [输入框] │
└──────────┴───────────────────────────┴──────────┘
```

- **左栏**：历史任务列表，可切换/新建任务
- **中央**：主画布，三个标签页切换不同阶段
- **右栏**：Agent 对话栏，可与 AI 交流或查看提示信息

---

## 完成一次等效测试的完整流程

整个流程分四步，跟着页面指引操作即可：

### 第 1 步 — 设定原始组网参数

1. 点击左栏 **「+ 新任务」** 按钮，创建新会话
2. 中央画布上方会出现 **Step 1 — 等效参数设定** 表单，按以下方式填写：

   | 字段 | 说明 | 示例值 |
   |------|------|--------|
   | **模型名称** | 从下拉列表选择，选择后架构参数（L/H/A/dff/V）自动填充 | Qwen3-32B |
   | **设备类型** | 计算卡型号 | A3 |
   | **DP** | 数据并行度 | 8 |
   | **TP** | 张量并行度 | 16 |
   | **PP** | 流水线并行度 | 8 |
   | **L (层数)** | 模型层数，选模型后自动填 | 64 |
   | **H (隐藏维度)** | 模型维度，选模型后自动填 | 4096 |
   | **A (头数)** | 注意力头数，选模型后自动填 | 32 |
   | **b (micro batch)** | 微批次大小 | 4 |
   | **dff** | FFN 中间维度，选模型后自动填 | 14336 |
   | **V (词表)** | 词表大小 | 32000 |
   | **S (序列长度)** | 训练序列长度 | 2048 |
   | **B (批次大小)** | 总批次大小 | 32 |

3. 在表单底部 **「默认等效策略」** 选择：
   - **最小集群等效**：减少集群规模，保持算力大致不变（推荐）
   - **单卡极限等效**：极限压缩到单卡/少卡场景
4. 点击 **「确认提交」**

> 💡 选择模型名称后，L、H、A、dff 等架构参数会自动从模型库填充，无需手动输入。如果模型不在下拉列表中，也可以在右栏对话框输入模型名称（如 `Qwen/Qwen2.5-7B`），Agent 会自动从 HuggingFace 获取参数。

提交后，中央画布会渲染原始组网拓扑图（显示所有计算节点及其通信域分组），同时生成模型结构层级图。

---

### 第 2 步 — 等效计算推导

提交 Step 1 后，画布顶部的工作流进度条会推进到等效计算阶段。系统自动：

1. **逐条推送等效策略和公式** — 画布中会出现公式卡片，显示：
   - 等效策略说明（如：PP 从 8 减至 3，DP 从 8 减至 2）
   - 计算指标对比（FLOPs、HBM、通信量）
   - 等效公式推导过程

2. **自动生成等效组网拓扑** — 画布渲染第二组组网图

3. **生成等效模型结构** — 根据等效策略调整模型层数等参数

你可以通过点击组网图上的节点查看每卡的预估指标（FLOPs、HBM、通信量）。

> 此步在 API 模式下由表单自动触发，在 AI 模式下需在对话栏回复确认。

---

### 第 3 步 — 开始仿真

等效组网生成完毕后，画布上方工具栏的 **「开始仿真」** 按钮会变为可用状态。

1. 点击 **「开始仿真」** 按钮，弹出仿真参数面板：

   | 字段 | 说明 | 默认值 |
   |------|------|--------|
   | Epoch Num | 训练 epoch 数 | 1 |
   | Vocab Size | 仿真词表大小 | 18277 |
   | Frame | 训练框架 | Mindspeed |
   | Rank / Rank Range | 仿真卡范围 | 0 / 1023 |
   | 其他字段 | 一般保持默认即可 | — |

   > 大部分字段会从 Step 1 自动继承，无需修改。如无特殊需求，直接点击「开始仿真」。

2. 点击 **「开始仿真」**，页面自动切换到 **「等效仿真验证」** 标签页

3. 仿真运行期间：
   - 画布上方显示仿真状态（进度、日志）
   - 左右两组组网图逐步填入实际仿真数据
   - 每个节点可点击查看详细指标

4. 仿真完成后，按钮变为 **「重试仿真」**（如需重新运行）

---

### 第 4 步 — 查看等效结果

仿真完成后，切换到 **「等效结果」** 标签页，查看完整的对比报告：

| 指标 | 说明 |
|------|------|
| FLOPs 差异 (%) | 原始 vs 等效的单卡算力差异 |
| HBM 差异 (%) | 显存占用差异 |
| TP 通信差异 (%) | 张量并行通信量差异 |
| PP 通信差异 (%) | 流水线并行通信量差异 |
| DP 通信差异 (%) | 数据并行通信量差异 |
| **等效判定** | ✅ 等效验证通过 / ❌ 等效验证不通过 |

等效判定规则：所有指标差异 ≤ 5% 即判定为 **等效通过**。

## 两种操作模式

工具栏右侧有一个 **AI** 开关：

### API 模式（开关关闭）

- 通过表单按钮直接操作，流程清晰、步骤可控
- 适合标准化测试场景，无需对话
- 推荐 **新用户** 使用

### AI 模式（开关打开）

- 通过右栏对话栏与 Agent 交互
- 用自然语言描述需求，Agent 自动调用工具
- 适合灵活探索、参数不确定的场景
- 可直接输入模型名称（如 `帮我用 Qwen3-32B 做等效测试`），Agent 会自动填充参数

---

## 查看节点详情

在组网拓扑图上，鼠标悬停或点击任意节点，可以查看该卡的：

- **预估指标**（Step 1-2 阶段）：FLOPs、HBM、通信量估算值
- **仿真实测指标**（Step 3 之后）：来自仿真系统的真实数据

点击节点后弹出的详情面板包含：
- HBM 占用拆解（权重 / 梯度 / 优化器 / 激活值）
- TP / PP / DP 通信详情（次数、单次量、总量）
- 算子时间线（前向 / 反向 / 优化器各阶段耗时）

---

## 历史任务管理

- **左栏** 列出所有历史任务，显示拓扑标题和当前阶段
- 点击任意任务可恢复该会话的完整状态
- 点击 **「+ 新任务」** 开始新的等效测试

---

## 快捷操作

右栏对话区底部有快捷按钮（如 `A3 DP8/TP16/PP8 → A3 DP2/TP16/PP3`），点击即可一键填入常见参数组合并提交。

在对话栏输入框中按 **Enter** 发送消息，**Shift+Enter** 插入换行。

---

## 常见提示

| 提示 | 原因 | 处理方式 |
|------|------|----------|
| "模型 xxx 是稀疏(MoE)模型" | 输入了 MoE 模型（如 DeepSeek-V2） | 当前仅支持稠密模型，换选其他模型 |
| "无效设备类型" | 输入了非 A2/A3/A5 的设备 | 选择下拉列表中的合法设备类型 |
| "DP/TP/PP 值超出范围" | 并行度参数不合法 | 检查参数范围：DP 1-1024、TP 1-32、PP 1-128 |
| "仿真任务失败" | MCP 仿真服务未连接 | 确认仿真服务可用后点击「重试仿真」 |
| 模型参数未自动填充 | 模型不在内置目录中 | 使用完整仓库 ID（如 `Qwen/Qwen2.5-7B`）或在对话栏输入 |

---

## 操作流程一览

```
新任务 → Step 1 表单（选模型 + 设定 DP/TP/PP） → 确认提交
                                            ↓
                               画布渲染原始组网 + 模型结构
                                            ↓
                               Step 2 等效公式自动推送 → 等效组网生成
                                            ↓
                               「开始仿真」按钮可用 → 点击开始仿真
                                            ↓
                               仿真运行 → 节点数据逐步填入
                                            ↓
                               切换「等效结果」标签 → 查看对比报告
                                            ↓
                               ✅ 等效通过 / ❌ 等效不通过
```
